### 怎麼換圖

1. 把新圖存成**跟上表一模一樣的檔名**（包括 `.jpg` 副檔名）和尺寸
2. 在 GitHub 進到 `images` 資料夾 →「Add file」→「Upload files」→ 拖入新圖
3. 按「Commit changes」，1–2 分鐘後網站更新

提醒：
- 檔案盡量控制在 300KB 以下，太大會拖慢手機開頁
- 檔名不同的話網頁找不到圖，會變成空白
- 手機瀏覽器可能還留著舊圖，用無痕視窗確認最準
