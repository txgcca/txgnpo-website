# 學習地圖｜自製封面圖（備用）

一般情況下封面用「自動抓封面」或雲端共用連結即可。
只有抓不到、又想要最快最穩時，才把自製圖放這裡，並在 Sheet 的 coverUrl **只填檔名**（例如 `the-days.jpg`）。

| 類型 | 尺寸 | 比例 | 檔案大小 |
|---|---|---|---|
| 影片 | 1280 × 720 | 16:9 | ≤ 150 KB |
| 書籍 | 400 × 600 | 2:3 | ≤ 60 KB |
| Podcast | 400 × 400 | 1:1 | ≤ 40 KB |

- JPG、品質 75–80（可用 squoosh.app 壓縮）
- 檔名只用英文小寫、數字、連字號
